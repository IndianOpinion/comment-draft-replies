# Security policy

## Reporting a vulnerability

Please email hello@indianopinion.org with a description, the affected
version and steps to reproduce. Do not open a public issue for a security
problem.

We acknowledge reports within 3 working days and aim to send a fix or a
plan within 14 days. We credit reporters in the release notes unless you
ask us not to.

## Scope

Of most interest: any way to publish a draft without a logged-in person's
click, to see a draft without the review capability, to leak draft text to
the front end, a feed or a cache, to bypass the daily cap or the kill
switch, or to get reader data (email, IP address) sent to the model
provider.

## Supported versions

The latest release receives security fixes.
